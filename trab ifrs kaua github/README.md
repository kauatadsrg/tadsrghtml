## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (ex: `trabalho-frontend-logica-programacao`).
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No repositório, vá em **Settings > Pages**.
4. Em "Branch", selecione `main` e a pasta `/ (root)`, depois clique em **Save**.
5. Aguarde alguns minutos e acesse o link gerado (formato: `https://SEUUSUARIO.github.io/NOME-DO-REPOSITORIO/`).
6. Envie o link do GitHub Pages e o link do repositório no SIGAA até 23/08.

## Validação W3C

Antes de entregar, valide a página em https://validator.w3.org/ (aba "Validate by File Upload", enviando o `index.html`) e corrija qualquer erro apontado.
